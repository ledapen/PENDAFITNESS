# Dossier ECF — PENDAFITNESS

## 1. Analyse des besoins
Application de réservation d'activités sportives. Acteurs : visiteur, membre, coach, administrateur. User stories, critères d'acceptation, RGPD et contraintes responsive.

## 2. Conception UX/UI
Zoning, wireframes desktop/mobile, mockups haute fidélité, charte graphique (bleu nuit, orange, turquoise, jaune, violet), navigation et accessibilité.

## 3. UML et données
Cas d'utilisation, séquences (connexion, réservation, annulation, création d'une séance, administration), MCD/MLD, dictionnaire de données.

## 4. Front-end
HTML sémantique, Bootstrap, CSS responsive, JavaScript : menu mobile, filtres, mot de passe, confirmations.

## 5. Back-end
PHP MVC, PDO, CRUD, sessions, rôles, réservation avec contrôle de capacité, requêtes préparées, hashage, CSRF.

## 6. Tests
Navigation, inscription/connexion, contrôle des rôles, filtres, réservation, annulation, responsive, erreurs et sécurité.

## 7. Déploiement
Git/GitHub, Dockerfile, Render, TiDB Cloud, TLS, variables d'environnement, README et procédure de mise en production.
